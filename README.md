# MyNote 私有便签

MyNote 是一个可在家庭局域网使用的私有便签网站，采用 Flask + SQLite 构建。电脑负责运行服务，手机和平板连接同一 Wi‑Fi 后即可访问。

这是一个独立的开源项目，与 WPS 或金山办公没有隶属、授权或合作关系，也不包含其商标和专有素材。

## 功能

- 家庭多账号、数据相互隔离；首位注册者自动成为管理员
- “首页”默认分组、三栏桌面界面与手机分层界面
- 无需便签名称，直接输入正文；支持分组、搜索、置顶、自动保存、回收站
- 刷新后自动回到之前打开的分组和便签
- 富文本、清单、链接和图片
- 跨设备编辑冲突保护
- TXT、Markdown、JSON 导入
- Markdown、JSON 和包含图片的完整 ZIP 备份

## 启动

### 群晖 Container Manager（推荐）

不需要 Web Station，也不依赖群晖安装的 Python。容器使用固定的 Python 3.12 环境，并在异常退出或群晖重启后自动启动。

1. 将整个项目上传到群晖，例如 `/volume1/docker/mynote`。
2. 打开 Container Manager，进入“项目”，点击“新增”。
3. 项目名称填写 `mynote`，路径选择刚才上传的项目目录。
4. 来源选择已有的 `docker-compose.yml`，然后创建并启动项目。
5. 浏览器访问 `http://群晖IP:5055`。

群晖的 `5000` 端口通常已被 DSM 使用，因此默认将网站映射到 `5055`。如需修改，只需将 `docker-compose.yml` 中的 `5055:5000` 左侧数字改为其他未占用端口。

数据库、附件和会话密钥会保存在项目目录下的 `instance` 文件夹。升级或重新构建容器不会删除该文件夹。不要把 `instance` 文件夹放在远程 SMB/NFS 挂载中，SQLite 应使用群晖本机存储。

更新程序文件后，在 Container Manager 的项目页面选择“操作 → 构建”，完成后重新启动项目。查看运行问题时，打开 `mynote` 容器的“日志”页面。

### Windows

在 Windows 上双击 `start.bat`。首次启动会自动安装项目依赖并创建数据库，窗口中会显示两个地址：

- 电脑访问：以启动窗口显示为准，通常是 `http://127.0.0.1:5000`
- 手机访问：使用窗口显示的地址，例如 `http://<电脑局域网IP>:5000`

如果 `5000` 被 Docker Desktop、Hyper-V 或其他程序占用/保留，启动脚本会自动改用 `8055`–`8057`，请始终使用窗口中显示的实际地址。

手机和电脑必须连接同一个 Wi‑Fi。运行服务的窗口不能关闭；按 `Ctrl+C` 可以停止服务。

如果 Windows 防火墙首次询问是否允许访问，请只勾选“专用网络”。

## 第一次使用

1. 打开网站并注册第一个账号。
2. 第一个账号自动成为管理员，可以在左下角账号菜单中关闭开放注册或停用家庭成员账号。
3. 其他家庭成员在自己的手机或电脑上打开相同局域网地址并注册。

## 数据与备份

所有持久数据都在项目的 `instance` 文件夹：

- `instance/mynote.sqlite3`：账号、分组和便签
- `instance/uploads`：便签图片
- `instance/.secret_key`：登录会话密钥

推荐定期在“账号与数据”中下载“完整 ZIP 备份”。也可以在停止 MyNote 后，直接复制整个 `instance` 文件夹。

请勿在服务运行期间只复制 SQLite 主文件，因为 WAL 模式下可能还有尚未合并的数据。

## 命令行运行与测试

```powershell
uv sync
uv run pytest
uv run waitress-serve --listen=0.0.0.0:5000 --call mynote:create_app
```

## 安全提示

本项目默认面向可信家庭局域网，不应直接把 `5055` 端口映射到公网。如果以后需要在外网访问，请先配置 HTTPS、可信反向代理、访问频率限制和可靠的异地备份。
